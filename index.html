Principle

No stock markup carried over — and every existing feature must survive. Styling a surface is not the same as preserving it, so a checkbox is only ticked when the feature is genuinely wired. Progress is reported honestly: a build is not called green until it is green.

舊 markup 一件都唔留,但係功能一個都唔准少。畫靚咗個樣唔等於功能仲喺度, 所以要真係駁通咗先剔。未綠就係未綠,唔會當佢綠。
